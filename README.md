# Anas Chater — Cybersecurity e-portfolio

A responsive, single-file website for a final-year cybersecurity engineering student.

## Open locally

Double-click `index.html` in a browser. No installation, server, framework, or internet access is required for the layout and filters.

## Publish with GitHub Pages

1. Create a **public** GitHub repository called `AnasCHT.github.io` under the GitHub account `AnasCHT` (or use another repository name).
2. Upload `index.html` **and `Anas_CHATER_CV.pdf`** to the repository root and commit both files.
3. For a project repository, choose **Settings → Pages → Deploy from a branch → main → / (root) → Save**. The site should then appear at `https://AnasCHT.github.io/<repository-name>/`. For a user-site repository named `AnasCHT.github.io`, the address is `https://AnasCHT.github.io/`.
4. Wait for GitHub Pages to deploy.

## Customize before sharing

- Confirm technical descriptions and internship titles/dates.
- The PDF CV is already included and linked through the **Download CV** button. Keep `Anas_CHATER_CV.pdf` alongside `index.html` when publishing.
- Add LinkedIn or professional contact links if desired.
- Add real screenshots and links for academic projects after uploading documentation.
- If submitting to school, copy the published URL into your application PDF/email.

No third-party dependencies, analytics or contact-form backend are included. The email button opens the visitor's mail app.
